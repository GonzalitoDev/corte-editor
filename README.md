# Corte

Editor de video gratis que funciona en el navegador, sin marca de agua.

- Línea de tiempo con 4 pistas: texto, capa, principal y audio
- Recortar, dividir, duplicar, deshacer y rehacer
- Textos animados, fondos con degradado, filtros y ajustes de imagen
- Velocidad, volumen y fundidos
- Formatos 16:9, 9:16, 1:1 y 4:5
- Exporta a MP4 (Chrome/Edge) o WebM (Firefox)

Todo corre en el navegador: los archivos que importás no se suben a ningún servidor.

## Uso

Es un sitio estático de un solo archivo. Abrí `index.html` o publicalo en Vercel, Netlify o GitHub Pages.
